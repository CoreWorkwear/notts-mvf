# Notts MvF — Glossary & Domain Language

Companion to HANDOVER.md. Locks the club's terms and the language rules so the build (and any new copy, empty states, notifications, AI output) stays consistent and in the right voice. When in doubt, this doc wins on wording.

---

## Club structure

- **Nottinghamshire MvF** — the club. Founded 2020, Robin Hood / hooded-archer crest, part of the Men v Fat ecosystem. Unofficial 11-a-side, played on 3G/4G.
- **XL 11s** — the **first team**. Brand colour **red**. The senior side. Listed first everywhere. Sometimes "the firsts", "XL".
- **Community** — the **reserves**. Brand colour **green**. The second team / pathway side. Sometimes "the Community team", "the reserves".
- **One club, two teams.** A player can belong to one or both. Stats roll up to the **club** but split by **team** (the FM model).

## Roles & permissions

- **Manager / Admin** — manages everything. "Manager" in player-facing copy, "Admin" in UI labels. Created only by other admins. (Club preference, set 2026-06: use **Manager**, not "Gaffer".)
- **Player** — default role. Sets own availability, edits own profile.
- **XL eligibility** — a flag that lets a player see and respond to **XL 11s** fixtures. Granted by an admin, never self-claimed. Without it, XL games are invisible to that player.
- **Active / Inactive** — inactive players (left the club, etc.) drop off squad lists but stay on past results. Never hard-deleted.

## Match & football terms

- **Fixture** — a scheduled game. Has a **type**: League, Friendly, Cup, Other.
- **League** — the named competition a league fixture belongs to (e.g. MvF XL National League). Friendlies have none.
- **Result** — the outcome of a played fixture: FT (full time) and HT (half time) score.
- **Kickoff (KO)** — start time.
- **Home / Away** — where it's played; in listings the home team is named first.
- **Subs** — match fee, £7 per player per game. (Not "dues".)
- **Availability** — In / Maybe / Can't make it. Who's marked "in" is "who's in".
- **MOTM** — man of the match.
- **Golden Boot** — top scorer (club-wide or per team).
- **The squad / the players** — the players. Friendly, informal. (Club preference, set 2026-06: use **players**, not "lads".)
- **Pitch** — where it's played (never "field"). 3G/4G artificial.
- **Kit** — the strip (never "uniform" / "jersey").

## Language rules (enforced)

**British football vernacular throughout. Never Americanised.** This applies to all UI copy, empty states, button labels, notifications, and any AI-generated text.

| Use | Never |
|---|---|
| football | soccer |
| pitch | field |
| fixtures / results | schedule |
| squad / players | roster, the lads |
| kit | uniform, jersey |
| boots | cleats |
| manager | coach, gaffer |
| nil (spoken scores) | zero |
| match / game | matchup |
| table | standings (US sense) |

Tone: casual, direct, working-class, matchday. Short and plain. "I'm in", "Can't make it", "Who's in", "Nothing in the diary yet". No corporate filler, no AI-sounding phrasing, especially in anything WhatsApp-bound.
